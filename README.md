# Ethical Hacking Intelligence Automation Platform

A cyber threat intelligence (CTI) automation platform built from the ground up,
combining automated collection of threat feeds, IOC extraction, and security
domain-specific analysis tooling (API, Web, Network, Cloud, Mobile, and Web3
security) into a single intelligence pipeline.

## Status
🚧 Early development — Phase 1: Project Setup

## Stack (planned)
- Python 3.13
- Telegram Bot API (alerting)
- SQLite → PostgreSQL (data storage, will evolve over phases)
- FastAPI (backend API)
- Web dashboard frontend
